# Snake & Ladder Game

A simple and attractive Snake & Ladder browser game built as a single HTML file.

## Features
- Clean modern UI
- 10x10 game board
- Dice rolling
- Turn-based multi-player gameplay
- Snake and ladder logic
- Reset game button
- Responsive layout for desktop and smaller screens

## Project Structure
This project is intentionally kept simple and lightweight:

- `index.html` — contains the full game UI, CSS styling, and JavaScript logic in one file

## How to Run
1. Open `index.html` in your browser.
2. Click the `Roll Dice` button to play.
3. The active player moves across the board.
4. Landing on ladders moves you up and landing on snakes brings you down.
5. First player to reach square 100 wins.

## Notes
This is a static web app, so no separate CSS or JavaScript files are needed. Everything is embedded directly inside `index.html` for easy sharing and portability.

## Example
```bash
# Just open this file in the browser
open index.html
```

On Windows, you can double-click `index.html` or open it in a browser.
